# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML with Tailwind CSS from its CDN, custom CSS and JavaScript, and Google Fonts, matching the supplied reference site's stack.

## Users
Mac users who want to open multiple Roblox accounts, and visitors deciding whether to install RbxMulti.

## Product Purpose
Explain RbxMulti, link to its current download and help resources, and help Mac users manage multiple Roblox player sessions from one menu-bar app.

## Positioning
RbxMulti routes browser Play links to separate Roblox player sessions and keeps its manager available in the macOS menu bar.

## Operating Context
The website is a companion to a native macOS app. Users install the official Roblox app first, then use the browser to launch a session for each signed-in account.

## Capabilities and Constraints
- The app supports macOS 13 or later on Apple silicon and Intel Macs.
- The app can show account names, avatars, running player processes, and session warnings.
- Player process status does not confirm a live game connection. RbxMulti does not simulate input or promise an idle timeout will be prevented.
- The website must link to the real GitHub releases, user guide, troubleshooting, privacy, and contributing resources. Do not invent contact details, release builds, or testimonials.
- Roblox software, assets, and trademarks remain outside this project’s license.

## Brand Commitments
Use the RbxMulti name and existing app icon. The native app uses a purple accent; the requested website reference uses a clean light canvas and blue accents.

## Evidence on Hand
Product facts are documented in README.md and docs/. The existing app icon is Resources/icon_1024.png. No marketing screenshots or testimonials are supplied.

## Product Principles
- Describe behavior the app actually implements.
- Make the current download and setup guidance easy to find.
- Keep the site lightweight and readable across screen sizes.
- Respect reduced-motion preferences.

## Accessibility & Inclusion
Support keyboard navigation, visible focus, responsive layouts, and reduced-motion preferences.
